# LiteBus brand assets

`icon.png` is the 128 by 128 raster reference used by NuGet packages. `icon.svg` is its
resolution-independent equivalent. `litebus-logo.svg` combines the same mark with the LiteBus
wordmark for repository and documentation headers.

## Palette

| Role | Hex |
| --- | --- |
| Lightning outline and wordmark | `#3E3643` |
| Lightning route | `#FDBF00` |

Keep the mark's `128 128` view box and an 8-unit rounded outline when resizing or deriving a new
asset. Do not stretch the mark independently from the wordmark or place text inside its clear area.
