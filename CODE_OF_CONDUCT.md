# Code of conduct

LiteBus is committed to a welcoming, respectful, and harassment-free community.

Participants must communicate professionally, welcome different viewpoints, give and
receive actionable feedback, and protect private information. Personal attacks,
harassment, discrimination, sexualized conduct, threats, doxxing, and deliberate
disruption are not acceptable.

Report concerns privately through the security contact in the repository profile. Project
maintainers will review reports, protect confidentiality where possible, and take any
action needed to keep participation safe.
