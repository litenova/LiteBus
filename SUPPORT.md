# Support

Use GitHub Discussions for usage questions and design conversations. Use GitHub Issues for
reproducible bugs, missing documentation, and actionable feature requests.

Before opening a request, search existing discussions and issues, include the LiteBus
version and target framework, and provide a small reproduction. For transport or storage
issues, include the selected adapter and whether the failure occurs with the in-memory
provider.

Security reports must follow [`SECURITY.md`](SECURITY.md), not a public issue.
